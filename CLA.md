# Contributor Licence Agreement

> **This document has not yet been reviewed by a solicitor.** It is written to be clear and
> to do a specific job, and it is modelled on the widely used Apache Individual Contributor
> Licence Agreement. Get it reviewed before relying on it for anything commercial. If you
> are contributing and this worries you, say so in your pull request and it will be
> discussed rather than waved through.

## Why this exists

Senbonzakura is licensed under the GNU Affero General Public Licence, version 3 or later,
and the intention is that it stays that way. Nothing here changes the licence you receive
the code under.

What it does is keep one future option open. If the project ever needs to offer the same
code to an organisation under different terms, for example a company that cannot take AGPL
code into its product, that requires permission from everyone who wrote part of it. Asking
for that permission later, from every past contributor, is often impossible: people change
jobs, change email addresses, and sometimes cannot be found at all. A single project that
skipped this step has to rewrite the contributions it cannot get permission for.

Signing this now costs you nothing and costs the project nothing. Not signing it now can
close the option permanently.

You keep the copyright in what you write. This is a licence, not a transfer of ownership.

## How to sign

Add a line to `CONTRIBUTORS.md` in your first pull request:

```
Name <email>  YYYY-MM-DD  I agree to the CLA in CLA.md.
```

That is the whole process. There is no form to fill in and no account to create.
